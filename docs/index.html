ASTRA · 0.1.16 DESKTOP PREVIEW

Read across languages.
Keep the context.

A Chromium desktop browser with paragraph translation, a personal vocabulary book and a ZenMux AI workspace beside your tabs. Available for macOS, Windows and Linux.

macOS · Apple Silicon macOS · Intel Windows · x64 Linux · DEB Linux · RPM Linux · AppImage

Version 0.1.16 is available for macOS Apple Silicon and Intel, Windows x64, and Linux x64. Both macOS DMGs are notarized and contain signed applications. The Windows installer is unsigned. Release notes and SHA-256 checksums.

NEW IN 0.1.16

Open Notebook. Copy images.

Google Notebook loads normally after sign-in with strict protection enabled. Image context menus now offer Copy image and Copy image address, using Chromium’s native clipboard without requiring page canvas access. Selection copying and editable-field pasting are also available.

NEW IN 0.1.15

Download updates reliably

Fixes connection-closed errors while downloading updates from GitHub. If an older version cannot download the update, install 0.1.15 once to receive the fix.

NEW IN 0.1.14

Render interactive 3D lessons

WeduLab contour lessons can render their 3D terrain with strict fingerprint protection enabled. The update dialog also shows both the installed version and the latest available version.

NEW IN 0.1.13

Download long videos in time ranges

Choose 5-, 10-, or 30-minute ranges. Two ranges can run together, with processing progress and retries for unfinished ranges. Completed ranges are combined into one file. Exact cuts re-encode the video, so processing can take additional time.

Select individual videos in multi-video posts or media already loaded by a page. Open saved files or their folder, and move a completed download together with its intermediate ranges to the system Trash after confirmation. Completed download records remain available after restart.

FULLSCREEN & PHOTOS

Video fullscreen and X photo controls

Use the player fullscreen button on YouTube or X, then press Escape to return to the browser layout. Open a photo on X to zoom with the controls or scroll, then drag the enlarged photo to pan.

NEW IN 0.1.12

Check for updates in Astra

Open About → Update in an installed build to check GitHub for a newer version. X and Grok use native browser APIs for compatibility while strict fingerprint protection stays enabled by default.

Your vocabulary, one page at a time

Read one saved entry per page, or choose 5, 10 or 20. Move between pages or jump to a page number. Find words, meanings and original context with local fuzzy search, including small spelling differences in Latin words. Exports still contain your complete dictionary.

Connect other AI applications through MCP

Enable the authenticated local MCP server in Settings and copy the Codex or JSON configuration. Clients can inspect tabs, read pages and capture screenshots. A separate automated page actions switch allows clicks, typing, scrolling and navigation. Both switches default to off; credentials stay encrypted locally. The AI sidebar divider can be dragged to adjust reading space.

Follow ordinary file downloads

The download shelf shows received and total size, percentage, transfer speed and remaining time when the server provides a total. Unknown-size downloads still show bytes and speed. Recoverable interruptions retry up to three times, with manual resume or restart available. Cancelled entries disappear from the list. Resume support depends on the server and is limited to the current browser session.

Choose your search engine

Settings offers 15 providers, including Google, Bing, Baidu, DuckDuckGo, Yahoo, Yandex, Brave Search, Ecosia, Qwant, Startpage, Sogou, 360 Search, Naver, Yahoo Japan and Daum. Your saved choice applies to address-bar searches and new tabs, while explicit website addresses open normally.

RESIZABLE WORKSPACE

A sidebar that moves with you

Drag the visible divider between the webpage and AI sidebar in either direction. Both areas resize together, and your width is remembered when you close the sidebar or restart. Keyboard arrows adjust the divider too.

TRANSLATION & DICTIONARY

Translate the paragraph.
Remember the word.

Read the original and translation together, or choose translation only. New text continues translating as the website loads it. Follow progress, stop requests, retry failed blocks or restore the original page.

Long passages are split without truncation. Original links and elements stay in place. Code blocks are kept intact, while inline identifiers such as stream=True remain part of the surrounding translation context.

  1. 1. Open TranslateUse the toolbar to choose a target language and display mode independently from the website language.
  2. 2. Select a word and right-clickGet its meaning, part of speech, contextual explanation, original passage and passage translation. Save it to your user dictionary.
  3. 3. Keep your vocabularyOpen User dictionary from the toolbar or Settings. Entries retain source titles and URLs. Export everything as JSON or Markdown.

Tested on a BBC news article and the OpenAI streaming responses guide: bilingual text, failed-block retry, code preservation, contextual word saving, persistence after restart and both export formats. This is a preview, with site-dependent compatibility.

More of your workflow, in one window

AI beside the page

Streaming Markdown answers in a compact, resizable sidebar. Include page text, attach a webpage screenshot, or add up to five files by selection, drag-and-drop or paste. Copy prompts and answers.

Your key, your model

Connect a ZenMux API key and choose a model. Separate key and model tests help check your configuration. A registration link is available if you do not have a key.

Inspectable browser actions

Request page actions through the AI sidebar. Review snapshots, action history, approval prompts and completion assessment, with controls to stop or continue tasks.

Media tools

Discover supported media formats and resolutions, select a download and follow progress and speed. Video summaries sample eight frames for a vision-capable model; they do not analyze audio.

Everyday browsing

Bookmarks, history and cookie controls; collapsible tab and AI panels; Chinese-first interface labels with English secondary copy; independent website language and timezone settings.

Browser privacy controls

WebRTC protection, secure DNS, Do Not Track and Global Privacy Control signals, with strict fingerprint restrictions and selected site compatibility exceptions. Follow the system proxy or configure a manual proxy.

Native app links

Open supported App Store product links in the macOS App Store. Confirm Tencent Meeting links before handing them to the installed client. External applications use their own network settings.

A local vocabulary book

Store each word with its meaning and source context. Repeated words from different passages can remain separate entries. JSON exports preserve structured fields; Markdown exports are easy to read and share.

Sign-in compatibility and diagnostics

Supported identity-provider popups share the initiating tab’s browser session. Export login diagnostics from Settings to investigate failures across machines. Sign-in behavior depends on the site and account.

What to expect from this preview

AI features require your ZenMux key and model access. Translation sends the requested page text or selected passage to the configured model. Saved vocabulary and dictionary filtering stay local until you export or share entries. Address-bar search queries go to your selected search provider. AI explanations and completion assessments can be wrong.

Translation covers loaded webpage text, including supported frames. It does not read text inside images, canvas, closed shadow roots or rendered PDFs. Media availability depends on the site and access conditions. X Guard and full Swift feature parity remain incomplete. Windows and Linux packages are built in CI; the latest real-site interaction tests were run on macOS.

Privacy protections reduce exposure; they do not guarantee anonymity, make fingerprints untraceable or hide proxy/VPN use. Strict protection can affect site functionality. App Store launch was tested, but direct arrival at a specific product detail was not confirmed.
